# Dashboard surface brief

- Mode: Operate
- Audience: developers/operators inspecting their own Access-protected Clankwerk project.
- Task: search definitions and entrypoints, follow a workflow to runs, inspect mediated agent calls and accepted API starts, and choose a comfortable theme.
- Constraint: read-only project configuration; theme/collapse are browser-local. Real data only. No public trigger routes or direct-agent session indexing.

## Direction contract

**THESIS:** a clear operational map from definitions to executions, not a decorative hero or a wall of metrics. Cloudflare's dashboard is a reference for orientation and density, not an identity to copy.

**OWN-WORLD:** quiet off-white navigation rail, open white work surface, precise hairline boundaries, copper interaction accent and semantic status color. One restrained workhorse sans with tabular data. No decorative cards or false charts.

**STORY:** the operator finds an agent or workflow, follows the source graph into a run and its steps/events, and sees actual workflow-mediated agent calls and an accepted API-start origin. Older runs and unmediated traffic stay explicitly unclaimed.

**FIRST VIEWPORT:** project identity and a gently turning cog, working quick search directly beneath it, Overview then expandable Agents/Workflows/Triggers and Audit log, Settings across a divider, and a quiet bottommost icon-only collapse control. The overview keeps its compact definition/entrypoint columns and recent runs without a second search field. Empty states remain honest; no utility bar or fabricated measurements.

**FORM:** operator console with a fully visible mobile navigation group, real collapsible source-item submenus on desktop, persistent rail collapse and keyboard quick search, a browser-local Light/Dark/Auto Settings choice, linked entity and entrypoint rows, a manifest graph, tables and recorded event times. Contextual back links work; there are no dead breadcrumbs. Cloudflare's product density is a reference, not a pixel template.

**FINISH:** verify both themes and Auto, collapse persistence, desktop/intermediate/phone paths with actual data, keyboard and axe; record remaining indexing/telemetry gaps without implying they are implemented.
